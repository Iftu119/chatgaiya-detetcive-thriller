# চাটগাঁইয়া ডিটেকটিভ সিরিজ · ওয়েবসাইট

লেখক: **কাঠঠোকরা**। শুধু HTML, CSS আর JavaScript দিয়ে বানানো। কোনো build বা install লাগে না।

## ফোল্ডারে কী আছে

| ফাইল | কাজ | কতবার বদলাবেন |
|---|---|---|
| `series.js` | সব কেসের তালিকা (হোম পেজের কার্ড) | প্রতিটা নতুন কেসে |
| `stories/case-01.js` | কেস ০১-এর পুরো গল্প, সূত্র, চরিত্র | গল্প সম্পাদনা করলে |
| `stories/_template.js` | নতুন কেসের ফাঁকা কাঠামো | কপি করে ব্যবহার করুন |
| `assets/img/` | প্রচ্ছদের ছবি | নতুন কেসে নতুন ছবি |
| `index.html`, `read.html` | হোম পেজ আর পড়ার পাতা | সাধারণত না |
| `assets/css`, `assets/js` | ডিজাইন আর রিডার | সাধারণত না |

## GitHub-এ প্রথমবার তোলা
1. GitHub-এ নতুন **public** repository খুলুন, যেমন `chatgaiya-detective`।
2. **Add file › Upload files**-এ এই ফোল্ডারের ভেতরের সবকিছু টেনে দিন (ফোল্ডার কাঠামো ঠিক রেখে)। Commit করুন।
3. **Settings › Pages › Build and deployment**: Source = *Deploy from a branch*, Branch = `main`, ফোল্ডার = `/ (root)`। Save।
4. এক-দুই মিনিট পর সাইট চালু হবে: `https://<username>.github.io/chatgaiya-detective/`

## নতুন কেস যোগ করা (কেস ০২, ০৩ ...)

**ধাপ ১ · লেখা শুরুর আগেই "শীঘ্রই আসছে" কার্ড**
`series.js`-এ কেসের ব্লক যোগ করুন, `status: "soon"` রাখুন। হোম পেজে ডোরাকাটা কার্ড দেখাবে। (কেস ০২-এর কার্ড ইতিমধ্যে আছে।)

**ধাপ ২ · গল্পের ফাইল বানান**
`stories/_template.js` কপি করে নাম দিন `stories/case-02.js`। ভেতরে `id: "case-02"` লিখুন।

**ধাপ ৩ · লেখা বসান**
প্রতিটা অধ্যায় একটা `{ ... }` ব্লক। `text:` অংশের দুই ব্যাকটিক (\`) চিহ্নের মাঝে Word থেকে গল্প পেস্ট করুন।
- এক লাইন ফাঁকা = নতুন অনুচ্ছেদ
- `***` আলাদা লাইনে = দৃশ্য বদল
- `[clue:নাম]` আলাদা লাইনে = ওখানে সূত্র-কার্ড বসবে
- `“` দিয়ে শুরু হওয়া অনুচ্ছেদ নিজে থেকেই সংলাপ হিসেবে দেখাবে
- কোনো শব্দ বোল্ড করতে: `<b>শব্দ</b>`
- লেখার ভেতরে ব্যাকটিক (\`) চিহ্ন ব্যবহার করবেন না

প্রতিটা অধ্যায়ে `place` (📍 জায়গা), `time` (🕒 সময়) আর `day` (দিন-রেখায় কোন দিন; প্রথম দিন = 0) দিন। এগুলোই পাঠকের দৃশ্য-চিহ্ন।

**ধাপ ৪ · সূত্র-কার্ড**
`clues:` অংশে প্রতিটা সূত্রের সংজ্ঞা দিন। নম্বর (সূত্র ১, ২...) গল্পে যে ক্রমে আসে, সেভাবে নিজে থেকে বসবে। ধরনগুলো:
`screen` (যন্ত্রের স্ক্রিন), `message` (ফোনের মেসেজ), `ledger` (খাতা/রেজিস্টার), `versus` (দাবি বনাম প্রমাণ), `sketch` / `timeline` (SVG ছবি), `html` (যেকোনো কিছু)। উদাহরণ `case-01.js`-এ আছে।
caption-এ শুধু পড়ার নিয়ম লিখুন (কোন রং বা কোন শব্দের কী মানে), উত্তর না।

**ধাপ ৫ · চরিত্র**
`cast:`-এ প্রত্যেকের এক লাইনের পরিচয় আর `from:` (কোন অধ্যায়ে প্রথম দেখা)। পাঠক ওই অধ্যায়ে পৌঁছানোর আগে চরিত্রটা 👥 তালিকায় দেখাবে না। খুনির বর্ণনায় ইঙ্গিত দেবেন না।

**ধাপ ৬ · প্রচ্ছদ**
দুটো ছবি `assets/img/`-এ রাখুন: `case02-cover.jpg` (বড়, প্রায় ১৫৩৬×১০২৪) আর `case02-card.jpg` (ছোট, প্রায় ৭৬৮×৫১২)। নাম অবশ্যই `-cover` আর `-card` দিয়ে শেষ হবে।

**ধাপ ৭ · প্রকাশ**
`series.js`-এ কেসের `status: "published"`, `cover: "assets/img/case02-card.jpg"`, `title`, `blurb`, `length` ঠিক করুন।
GitHub-এ `series.js`, `stories/case-02.js` আর ছবিগুলো আপলোড করে Commit করুন। এক-দুই মিনিটে সাইটে চলে আসবে। হোম পেজের বড় ব্যানারে সবচেয়ে নতুন প্রকাশিত কেস নিজে থেকে দেখাবে।

## আপলোডের আগে নিজের কম্পিউটারে দেখা
`index.html` ডাবল-ক্লিক করে ব্রাউজারে খুলুন। ইন্টারনেট ছাড়াও চলবে (তখন বাংলা ফন্ট কম্পিউটারের ফন্ট থেকে আসবে)।
পাতা ফাঁকা দেখালে সাধারণত `case-02.js`-এ কোনো কমা বা ব্যাকটিক বাদ পড়েছে। Chrome-এ F12 চাপলে Console-এ লাল লেখায় লাইন নম্বর দেখাবে।
