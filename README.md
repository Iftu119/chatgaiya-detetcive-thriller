# চাটগাঁইয়া ডিটেকটিভ সিরিজ · ওয়েবসাইট

সাধারণ HTML/CSS/JS। কোনো build বা install লাগে না। GitHub Pages-এ সরাসরি চলে।

## ফোল্ডারের গঠন
```
index.html              মূল পাতা (কেসের তালিকা নিজে থেকে তৈরি হয়)
read.html               রিডার (সব কেস এই একটা পাতাতেই খোলে)
subscribe.html          ইমেইল সাবস্ক্রিপশন
feed.xml                RSS (নতুন কেস এলে আপডেট করবেন)
assets/js/config.js     সাইটের সেটিং: ছদ্মনাম, Buttondown username, ফেসবুক লিংক
stories/library.js      সব কেসের তালিকা
stories/case-01/        কেস ০১ (story.js + cover.jpg + card.jpg)
```
আপনি শুধু তিন জায়গায় হাত দেবেন: `config.js`, `stories/library.js`, আর `stories/case-XX/` ফোল্ডার।

## ১. প্রথমবার প্রকাশ করা
1. github.com-এ নতুন **public** repository খুলুন, নাম ধরুন `chatgaiya-detective`।
2. **Add file > Upload files** দিয়ে এই ফোল্ডারের ভেতরের সব ফাইল আর ফোল্ডার টেনে দিন (`.nojekyll` সহ)। **Commit changes**।
3. **Settings > Pages**: Source = *Deploy from a branch*, Branch = `main`, ফোল্ডার = `/ (root)`। **Save**।
4. এক-দুই মিনিট পর সাইট চালু: `https://<username>.github.io/chatgaiya-detective/`
5. `feed.xml`-এ `YOUR-USERNAME` বদলে আপনার GitHub username বসান।

## ২. সাবস্ক্রিপশন চালু করা (Buttondown)
GitHub Pages নিজে ইমেইল রাখতে বা পাঠাতে পারে না, তাই কাজটা করবে Buttondown।
প্রথম ১০০ জন সাবস্ক্রাইবার পর্যন্ত বিনামূল্যে।
1. buttondown.com-এ অ্যাকাউন্ট খুলুন। username ধরুন `kaththokra`।
2. `assets/js/config.js` খুলে লিখুন: `buttondown: "kaththokra",` তারপর Commit।
3. এখন সাবস্ক্রাইব পাতার ফর্ম চালু। পাঠক ইমেইল দিলে Buttondown তাকে একটা নিশ্চিতকরণ মেইল পাঠাবে।
4. **নতুন কেস প্রকাশ হলে:** Buttondown-এ গিয়ে নতুন মেইল লিখুন (শিরোনাম, দুই লাইন, লিংক) আর Send।
   বিনামূল্যের প্ল্যানে এটা হাতে পাঠাতে হয়। RSS দেখে নিজে থেকে মেইল পাঠানোর সুবিধা
   (RSS-to-email) Buttondown-এ আলাদা টাকার add-on।

## ৩. নতুন কেস যোগ করা (যেমন কেস ০২)

### ধাপ ১: ফোল্ডার বানান
`stories/case-01` ফোল্ডার কপি করে নাম দিন `stories/case-02`।
ভেতরে দুইটা ছবি রাখুন: `cover.jpg` (বড়, প্রস্থ ১২০০px-এর মতো) আর `card.jpg` (ছোট, প্রস্থ ৬৪০px-এর মতো)।

### ধাপ ২: `story.js` লিখুন
ওপরের অংশ:
```js
STORY({
  id: "case-02",              // ফোল্ডারের নামের সাথে হুবহু মিলতে হবে
  number: "০২",
  title: "কালুরঘাট",
  tagline: "এক লাইনের হুক",
  subline: "দ্বিতীয় লাইন (না চাইলে খালি)",
  cover: "cover.jpg",
  coverCode: "ছোট কোড-লাইন, না চাইলে খালি",
  people: [ ... ],
  chapters: [ ... ],
  clues: { ... }
});
```

**অধ্যায়** (`chapters`): প্রতিটা অধ্যায় একটা ব্লক। অনুচ্ছেদগুলো আলাদা আলাদা স্ট্রিং।
```js
{
  label: "অধ্যায় এক", title: "খুঁটি",
  where: "কালুরঘাট ব্রিজ", when: "সকাল ৮টা", day: "দিন ১",   // ওপরের ছোট ট্যাগ, না চাইলে বাদ দিন
  body: [
    "প্রথম অনুচ্ছেদ।",
    "দ্বিতীয় অনুচ্ছেদ। <b>মোটা অক্ষর</b> চাইলে এভাবে।",
    { clue: "belt" },                                    // এখানে সূত্র-কার্ড বসবে
    { sms: "মেসেজের লেখা", from: "পাঠানোর নাম" },        // ফোনের মেসেজ
    { pause: "ভাবার সময়: পরের অনুচ্ছেদে উত্তর।" }       // সমাধানের আগে থামার বক্স
  ]
}
```
ডায়েরির পাতার মতো দেখাতে অধ্যায়ে `diary: true` দিন।

**চরিত্র** (`people`): স্পয়লার এড়াতে `from` দিন। `from: 3` মানে অধ্যায় তিন পড়ার পর চরিত্রটা দেখাবে।
```js
{ name: "লাইনম্যান করিম", role: "পিডিবি", from: 1, icon: "⚡", text: "...",
  reveal: { at: 9, text: "শেষে যে তথ্য দেখাবে" } }
```

**সূত্র** (`clues`): পাঁচ রকম। প্রতিটায় `look` হলো পাঠককে কী খেয়াল করতে বলবেন (উত্তর না দিয়ে)।
```js
clues: {
  // যন্ত্রের স্ক্রিন / লগ  (<mark> দিয়ে লাইন হাইলাইট)
  meter: { title: "টেস্টারের স্ক্রিন", icon: "📟", type: "screen",
           lines: ["V: 000", "<mark>LAST: 11.2kV</mark>"],
           legend: [["kV", "হাজার ভোল্ট"]], look: "..." },

  // টেবিল (ফোনে নিজে থেকে কার্ড হয়ে যায়)
  log: { title: "ডিউটি রেজিস্টার", icon: "📒", type: "table", caption: "ঐচ্ছিক",
         head: ["সময়", "নাম", "কাজ"], rows: [["৮:০০", "করিম", "শাটডাউন"]], highlight: 0, look: "..." },

  // টাইমলাইন (ঘণ্টা দশমিকে: ১০:৩০ = 10.5)
  cam: { title: "ক্যামেরা", icon: "🎥", type: "timeline", start: 8, end: 12,
         ticks: ["৮:০০","৯:০০","১০:০০","১১:০০","১২:০০"],
         rows: [{ name: "ব্রিজ", off: [9, 10.5] }],
         marks: [{ at: 9.75, label: "৯:৪৫ ঘটনা", color: "#d9382b" }], look: "..." },

  // স্কেচ: যেকোনো SVG (case-01-এর sketch কপি করে বদলান)
  map: { title: "ঘটনাস্থল", icon: "✏️", type: "svg", svg: `<svg viewBox="0 0 360 400">...</svg>`, look: "..." },

  // যেকোনো HTML; spoiler: true দিলে চাপ না দেওয়া পর্যন্ত ঝাপসা থাকে
  board: { title: "কেস বোর্ড", icon: "🧩", type: "html", spoiler: true, html: "<ol class='steps'><li>...</li></ol>" }
}
```
সূত্র-কার্ড যে অধ্যায়ে বসাবেন, পাঠক সেই অধ্যায়ে পৌঁছালে সেটা 📌 তালিকায় জমা হবে।

### ধাপ ৩: তালিকায় যোগ করুন
`stories/library.js`-এ কেস ০২-এর ব্লক বদলে দিন:
```js
{ id: "case-02", number: "০২", title: "কালুরঘাট",
  blurb: "কার্ডে দেখানোর দুই-তিন লাইন",
  place: "কালুরঘাট", chapters: "১০ পর্ব", minutes: "প্রায় ৩০ মিনিট", date: "জানুয়ারি ২০২৭",
  status: "published" }
```
পরের কেসের ঘোষণা দিতে চাইলে নিচে `status: "soon"` দিয়ে কেস ০৩-এর ব্লক যোগ করুন।
মূল পাতা, রিডারের "পরের কেস" কার্ড সব নিজে থেকে আপডেট হবে।

### ধাপ ৪: প্রকাশ আর জানানো
1. `feed.xml`-এ নতুন `<item>` সবার ওপরে বসান।
2. হোমপেজের বড় ছবি নতুন কেসের করতে চাইলে `index.html`-এ `stories/case-01/cover.jpg` বদলে `case-02` লিখুন।
3. GitHub-এ ফাইলগুলো আপলোড করে Commit। এক-দুই মিনিটে সাইটে চলে আসবে।
4. Buttondown থেকে সাবস্ক্রাইবারদের মেইল পাঠান। লিংক: `.../read.html?case=case-02`

### ভুল হলে কোথায় দেখবেন
- কেস খুলছে না, "প্রকাশ হয়নি" দেখাচ্ছে: `id`, ফোল্ডারের নাম আর `library.js`-এর `id` তিনটা হুবহু এক কি না দেখুন।
- পাতা ফাঁকা: `story.js`-এ কোনো কমা বা উদ্ধৃতিচিহ্ন ছুটে গেছে। প্রতিটা অনুচ্ছেদ `"..."` দিয়ে ঘেরা আর শেষে কমা আছে কি না দেখুন।
  গল্পের ভেতরের উদ্ধৃতিতে বাংলা “ ” ব্যবহার করুন, সাধারণ `"` না।
- আপলোডের আগে পরীক্ষা: `index.html` ফাইলে ডাবল-ক্লিক করলেই ব্রাউজারে চলে।
